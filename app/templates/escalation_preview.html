Why this page exists

The first fair question about a system that emails the CMD is “who is about to be emailed, and about what”. The only honest way to answer it is to run the whole check — the same overdue list, the same ladders, the same decision about what is owed next — and stop short of the database row and the email. That is this page. It is Phase 5 of the approved roadmap without the CMD's inbox being where the testing happens.
